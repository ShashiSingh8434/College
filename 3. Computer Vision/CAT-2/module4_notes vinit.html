K-Means & K-Medoids ClusteringUnsupervised · Partition-based
DEF

Partition-based clustering algos that group data into K clusters, each represented by a center (centroid or medoid).

THEORY
  • K-Means center = mean (virtual pt)
  • K-Medoids center = real data point
  • K assumed known beforehand
  • Medoids robust to outliers
SOLVES

Grouping unlabeled data into K natural clusters minimizing within-cluster distance.

STEPS
  1. Choose K, init K centers randomly
  2. Assign each pt to nearest center
  3. Recompute center (mean / medoid)
  4. Repeat till centers stop changing
MATH minimize Σ dist(xi, centerk)²  (EM-style: assign=E-step, update=M-step)
ADV

Simple, fast; K-Medoids robust to outliers; tighter clusters than hierarchical.

LIM

K must be pre-specified; sensitive to init & scaling; struggles with non-spherical shapes.

Gaussian Mixture Model & EMUnsupervised · Soft clustering
DEF

Probabilistic model assuming data is generated from a mixture of Gaussian (bell-shaped) distributions, one per cluster.

THEORY
  • Each cluster = 1 Gaussian(μ,Σ)
  • Soft clustering: prob. per cluster
  • Not hard 0/1 like K-Means
  • Params fit via EM algorithm
SOLVES

Clustering overlapping / elliptical clusters where hard boundaries fail.

STEPS
  1. Init K Gaussians: μ, Σ, weight Π
  2. E-step: est. prob. each pt→cluster
  3. M-step: update μ,Σ,Π from probs
  4. Repeat E & M till convergence
MATH N(x;μ,Σ) — Σ (covariance) shapes the bell curve; K-Means uses only μ, GMM uses μ+Σ
ADV

Handles soft/overlapping clusters; more flexible than K-Means.

LIM

Needs K known; can hit local optimum; computationally heavier.

K-Nearest Neighbours (KNN)Supervised · Lazy learner
DEF

Classifies a new point by majority vote among its K closest labeled neighbours.

THEORY
  • Non-parametric, no distribution assumption
  • Lazy: stores data, computes at test time
  • Similarity via distance metric
  • Best K found by trial (~5 typical)
SOLVES

Classify new data using similarity to existing labeled cases, no explicit training.

STEPS
  1. Select number of neighbours K
  2. Compute Euclidean dist. to all pts
  3. Take K nearest points
  4. Count class labels among K
  5. Assign majority class
MATH dist(p,q) = √Σ(pi − qi)²
ADV

Simple; robust to noisy data; effective with large training sets.

LIM

High compute cost (distance to all pts); choosing K is tricky; low K = noisy.

Naïve Bayes ClassifierSupervised · Probabilistic
DEF

Probabilistic classifier using Bayes' Theorem, assuming all features are independent of each other.

THEORY
  • "Naïve" = features assumed independent
  • "Bayes" = uses Bayes' Theorem
  • Great for high-D text data
  • Predicts via prob. of an object
SOLVES

Fast probabilistic classification — e.g. spam filtering, text classification.

STEPS
  1. Convert dataset into frequency table
  2. Build likelihood table of features
  3. Apply Bayes theorem → posterior prob.
  4. Predict class with highest posterior
MATH e.g. P(Yes|Sunny)=P(Sunny|Yes)P(Yes)/P(Sunny) = 0.60 > P(No|Sunny)=0.41 ⇒ Play
ADV

Fast, simple; handles binary & multi-class well; top pick for text classification.

LIM

Independence assumption rarely true → hurts accuracy when features correlate.

Multilayer Perceptron (ANN)Supervised · Feedforward NN
DEF

A feedforward artificial neural network mapping input data to outputs through one or more hidden layers.

THEORY
  • Feedforward: signal flows only forward
  • Layers of nodes in directed graph
  • Each layer fully connects to next
  • Each neuron ~ linear regression eqn
SOLVES

Learning complex, non-linear supervised input→output mappings.

STEPS
  1. Input layer receives feature values
  2. Hidden neuron: weighted sum+bias → activation
  3. Signal propagates forward, layer by layer
  4. Output layer gives final prediction
MATH output = f(Σ wixi + b)  — linear combo wrapped in activation f
ADV

Models complex non-linear relationships; general-purpose supervised learner.

LIM

Needs lots of data/tuning; acts as a "black box"; strictly forward-only signal flow.

Radial Basis Function (RBF) NetSupervised · 1 hidden layer
DEF

A supervised NN with exactly one hidden layer whose neurons respond based on distance from a fixed center.

THEORY
  • Only 1 hidden layer (vs many in MLP)
  • Hidden output = f(distance to center)
  • Centers NOT updated every iteration
  • Hidden neurons virtually independent
SOLVES

Fast-converging function approximation using localized, distance-based response.

STEPS
  1. Define centers for each hidden unit
  2. Compute distance: input → each center
  3. Radial function converts dist. to activation
  4. Output = weighted sum of activations
MATH hidden activation ∝ radial-fn( distance(x, centeri) ) — peak near center
ADV

Faster convergence than deep MLPs; simpler training (near-independent hidden units).

LIM

Only 1 hidden layer → limited to less complex mappings; centers must be chosen well.

Dimensionality ReductionOverview
DEF

Converting a high-dimensional dataset into a lower-dimensional one while preserving similar information.

THEORY
  • Dimensionality = no. of input features
  • Too many features → overfitting
  • 2 approaches: Selection & Extraction
  • Helps classification & regression fit
SOLVES

Overfitting from excess features; high storage/compute cost; hard-to-visualize high-D data.

SELECTION METHODS
  1. Filter: stat. test (Correlation, Chi-Sq, ANOVA, Info Gain) — model-free
  2. Wrapper: feeds subsets to ML model, evaluates (Fwd/Bwd/Bi-directional)
  3. Embedded: importance found during training (LASSO, Ridge, Elastic Net)
NOTE Extraction transforms space to fewer dims while keeping whole information.
ADV

Less storage & training time; faster visualization; removes multicollinearity.

LIM

Some data/information may be lost; optimal feature/component count often unknown.

Principal Component AnalysisUnsupervised · Feature Extraction
DEF

Converts correlated features into linearly uncorrelated "Principal Components" via orthogonal transformation.

THEORY
  • Considers variance of each attribute
  • High variance ⇒ good class split
  • Used in EDA & predictive modeling
  • Apps: image proc., recommenders
SOLVES

Compress high-D correlated data into fewer uncorrelated dims, minimal info loss.

STEPS
  1. Standardize the dataset
  2. Compute mean vector & covariance matrix
  3. Compute eigenvectors e1..d & eigenvalues λ1..d
  4. Sort by ↓λ, keep top k → matrix W (d×k)
  5. Project: y = WTx → new k-D sample
MATH y = WTx  (x: d×1, W: d×k eigenvectors, y: k×1 transformed)
ADV

Removes redundant/correlated features; speeds training; great for 2D/3D visualization.

LIM

Some info lost; ideal component count unclear; components hard to interpret.

Linear Discriminant AnalysisSupervised · Feature Extraction
DEF

Projects data onto a lower-D space that maximizes separability between known classes.

THEORY
  • Supervised (uses class labels)
  • PCA maximizes variance; LDA separation
  • Pre-processing for classification
  • Avoids overfitting, cuts compute cost
SOLVES

Reduce dimensions while keeping classes as distinguishable as possible.

STEPS
  1. Compute d-D mean vector per class
  2. Compute within-class & between-class scatter matrices
  3. Compute eigenvectors/values of scatter matrices
  4. Sort by ↓λ, keep top k → W (d×k)
  5. Transform: Y = X·W → new k-D subspace
MATH Y = X·W  (X: n×d samples, W: d×k eigenvectors)
ADV

Uses class info → often better than PCA for classification; reduces overfitting.

LIM

Needs labeled data; assumes ~Gaussian classes w/ similar covariance; max (classes−1) comps.

Independent Component AnalysisFeature Extraction · Source Separation
DEF

Reveals hidden structure by transforming mixed observed signals into a maximally independent set.

THEORY
  • Observed data = linear mix of latents
  • Mixing process is unknown
  • Independents: non-Gaussian & indep.
  • "Cocktail party" signal separation
SOLVES

Blind source separation — unmixing combined signals into original independent sources.

STEPS
  1. Collect mixed signals xi from sensors
  2. Model: xi = Σ aijsj (mixture of sources)
  3. Solve unmixing matrix W: si=Σwijxj
  4. Optimize W for max independence of {si}
MATH Goal: min mutual information OR max non-Gaussianity (kurtosis / negentropy)
ADV

Separates info (PCA only compresses it); ideal for signal/source separation.

LIM

Needs non-Gaussian sources; needs autoscaling; often benefits from running PCA first.

Optical Flow & Lucas-KanadeMotion estimation
DEF

Optical flow = apparent pixel motion between frames; Lucas-Kanade is the classic method to compute it.

THEORY
  • Track I(x,y,t) as pixels move (dx,dy)
  • Assume: intensity const. between frames
  • 1 eqn, 2 unknowns (u,v) → underdetermined
  • Lucas-Kanade adds local window to solve
SOLVES

Estimating per-pixel motion/velocity across video frames for tracking.

LUCAS-KANADE STEPS
  1. Assume constant intensity: I(x,y,t)=I(x+δx,y+δy,t+δt)
  2. Taylor-expand RHS, drop high terms → Ixδx+Iyδy+Itδt=0
  3. Divide by δt → flow eqn: Ixu+Iyv+It=0
  4. Use local window → solve ATA[u;v]=−ATb (least sq.)
MATH [ΣIxIx ΣIxIy; ΣIxIy ΣIyIy]·[u;v] = −[ΣIxIt; ΣIyIt]
ADV

Gives dense per-pixel motion vectors; well-grounded least-squares solution.

LIM

Fails on fast/large motion (small-motion assumption breaks); sensitive to lighting change.

Harris Corner & Motion TrackingFeature detection → Tracking
DEF

Harris Corner Detector finds edge-intersection "corners"; these salient points are then tracked across frames.

THEORY
  • Motion tracking: monitor a feature over frames
  • Apps: face detection, surveillance, traffic
  • Corner = intensity change in 2 directions
  • Challenges: fast motion, orientation, light, clutter
SOLVES

Choosing stable trackable points, then following them frame-to-frame.

STEPS
  1. Compute image derivatives Ix, Iy (Gaussian filters)
  2. Compute Ix², Iy², Ixy
  3. Sum products over a window → structure matrix M̂
  4. Cornerness R = detM−k(traceM)²; R>thresh ⇒ corner
  5. Track corners frame-to-frame via Lucas-Kanade
MATH R = detM − k(traceM)²,  detM=λ1λ2,  traceM=λ1+λ2
ADV

Detects stable, repeatable feature points; simple eigenvalue-based math.

LIM

Degrades under rapid motion, illumination change, or cluttered backgrounds.
