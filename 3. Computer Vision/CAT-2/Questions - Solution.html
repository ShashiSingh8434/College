Q1

Real-time feature extraction pipeline for pedestrian & vehicle detection in autonomous driving (night-time & rainy conditions)

⚙

1. Problem & Technique Selection

The application demands robustness to illumination degradation (rain, night), real-time speed (≥25 fps), and repeatability across scale for object matching. A single detector fails; a combined cascade pipeline is chosen: Scharr edges → FAST interest points → ORB descriptors, enriched with a multi-scale Gaussian pyramid.

3. Stage Explanations

S1

Gaussian Pyramid (5 levels)

Each level is formed by convolving with a Gaussian kernel G(x,y) and sub-sampling by 2, giving images at scales σ, 2σ, 4σ, … Pedestrians at 5 m and 40 m appear at different pyramid levels, enabling scale-invariant detection. Also smooths rain-streak noise before gradient computation.

S2

Scharr Edge Detection

Computes gradient magnitudes and orientations on each pyramid level. Sobel uses a 3×3 kernel with weights [1,2,1] / [-1,0,1], which has poor rotational isotropy. Scharr uses optimised weights that minimise rotational error, critical for slanted edges of vehicles in perspective. Canny adds hysteresis but is slower (2× more computation).

S3

FAST Interest-Point Detection

Tests 16 pixels on a Bresenham circle of radius 3. A point p is a corner if ≥9 contiguous pixels are all brighter or all darker than p by threshold t. FAST achieves ~100 fps vs. Harris at ~20 fps, critical for real-time. Non-maximum suppression removes duplicates using Harris score as tie-breaker. Shi-Tomasi improves Harris corner quality but FAST+NMS is the speed winner here.

S4

ORB Descriptor Extraction

ORB = Oriented FAST + Rotated BRIEF. It uses the intensity centroid to assign a canonical orientation θ to each keypoint, then applies steered BRIEF: 256 binary comparisons of smoothed pixel pairs in a rotated patch. The descriptor is a 256-bit string, enabling Hamming-distance matching in O(n/64) with bitwise XOR. Unlike SIFT (128-D float), ORB is 64× more memory efficient and patent-free.

S5

Hamming-Distance Matching + RANSAC

Match descriptors from current and reference frames; prune with RANSAC to find a consistent homography, confirming vehicle/pedestrian candidates.

∑

C = (m₁₀/m₀₀ , m₀₁/m₀₀), θ = atan2(m₀₁, m₁₀)

Advantages

  • Real-time capable (>30 fps on embedded GPU)
  • Rotation & scale invariant
  • Robust to mild illumination change (Scharr isotropy)
  • Memory-efficient (256-bit ORB vs 512-byte SIFT)
  • Patent-free (ORB)

  • Binary descriptors degrade with heavy blur (rain drops)
  • Rain streaks at night can create false edges
  • RANSAC non-deterministic — may fail under occlusion
Q2

Interactive segmentation pipeline for 3-D MRI tumour extraction with intensity inhomogeneity and weak boundaries

⚙

1. Problem & Technique Selection

MRI volumes exhibit bias-field inhomogeneity (slow intensity drift), weak boundaries, and topology sensitivity. A single method fails: Watershed alone over-segments; Snakes leak through weak edges; Graph-Cut without initialisation is underconstrained. The chosen pipeline: Active Contours (Level-Set) → Watershed (marker-controlled) → Graph-Cut (with user seeds).

3. Stage Explanations

S1

Bias-Field Correction (N4ITK)

Estimates and removes the slow-varying multiplicative bias field B(x) where observed intensity I(x) = B(x)·T(x) + n(x), T(x) = true tissue intensity. Ensures Watershed thresholds are meaningful.

S2

Level-Set Active Contour (Chan-Vese)

Represents the evolving boundary as the zero-level of a signed distance function φ(x,t). Energy functional E = λ₁∫(I−c₁)²dΩ₁ + λ₂∫(I−c₂)²dΩ₂ + μ·|∂Ω|. User places an initial ellipsoid seed around the tumour; the contour evolves via gradient descent on E, stopping at the weak boundary where intensity gradient is small. Handles topology changes (tumour splitting) unlike parametric Snakes.

S3

Marker-Controlled Watershed

The level-set result provides foreground markers; user scribbles on background provide background markers. The gradient magnitude image is treated as a topographic map; flooding from markers prevents over-segmentation. Each catchment basin corresponds to a region. Stops leakage across weak boundaries by confining flooding to marker-controlled basins.

S4

Graph-Cut Refinement

Construct graph G=(V,E): each voxel is a node. Terminal edges (t-links) encode P(voxel ∈ tumour) from appearance model; neighbourhood edges (n-links) encode boundary penalty. Min-cut = max-flow (Ford-Fulkerson) finds globally optimal binary labelling, refining the boundary at pixel level. User scribbles add hard constraints (seeds) on t-link weights.

∑

4. Mathematical Principles

Chan-Vese Level-Set Energy E(φ,c₁,c₂) = μ∫|∇H(φ)|dx + λ₁∫(I−c₁)²H(φ)dx + λ₂∫(I−c₂)²(1−H(φ))dx
∂φ/∂t = δ(φ)[μ·div(∇φ/|∇φ|) − λ₁(I−c₁)² + λ₂(I−c₂)²]
Graph-Cut Min-Cut / Max-Flow E(L) = Σ_p θ_p(L_p) + Σ_{(p,q)∈N} θ_{pq}(L_p,L_q)
θ_p(0) = −log P(I_p | background), θ_p(1) = −log P(I_p | tumour)
θ_{pq}(L_p≠L_q) = exp(−(I_p−I_q)²/2σ²) / dist(p,q)
✓

5. Justification & Order

Level-Set first provides a coarse, topologically flexible initialisation that handles the tumour's irregular shape. Watershed then exploits this to avoid the classic over-segmentation problem. Graph-Cut last delivers globally optimal refinement with user-interactive constraints, ensuring precise boundary delineation for subsequent volumetry.

Advantages

  • Handles topology changes (Level-Set)
  • Leakage prevention (markers in Watershed)
  • Global optimality (Graph-Cut)
  • Interactive via seeds/scribbles
  • Topologically correct masks for shape analysis

Limitations

  • Level-Set re-initialisation needed to avoid numerics
  • Watershed still may over-segment near noise
  • Graph-Cut: memory O(V+E) — large 3-D volumes costly
  • User seed quality critically affects result
Q3

Hybrid anomaly-detection scheme for high-dimensional IoT sensor streams

⚙

1. Problem & Technique Selection

IoT streams are high-dimensional, largely unlabelled, subject to concept drift, and contain very few confirmed anomaly labels. A two-stage hybrid is chosen: DBSCAN (unsupervised clustering) followed by One-Class SVM (semi-supervised boundary).

3. Stage Explanations

S1

Feature Extraction & Windowing

Sliding window of W samples; compute time-domain (mean, variance, RMS) and frequency-domain (top-k FFT coefficients) features. Apply Incremental PCA to project to d-dimensional subspace (d≪original), removing correlated sensor noise.

S2

DBSCAN Clustering

Groups unlabelled normal data without specifying k. Parameters: ε (neighbourhood radius), MinPts. Core points have ≥ MinPts in ε-ball. Points not reachable from any core point are labelled as noise — these become initial anomaly seeds. DBSCAN's density-based criterion makes it robust to outliers and arbitrary cluster shapes, unlike K-Means which forces spherical clusters.

S3

One-Class SVM

Trained on normal cluster members. Finds a hyperplane in kernel feature space that separates normal data from the origin with maximum margin ρ. Decision function: f(x) = sign(Σ αᵢ K(xᵢ,x) − ρ). A new sample with f(x)<0 is declared anomalous. RBF kernel used for non-linear boundary. ν hyperparameter upper-bounds the fraction of outliers in training set.

S4

Online Decision & Model Update

Sliding window re-runs DBSCAN every T seconds. Confirmed normal points (high confidence) are added to OC-SVM support vector set via incremental update. Concept drift is handled by exponential forgetting: old support vectors are down-weighted over time.

∑

4. Mathematical Principles

DBSCAN Core Point Criterion Core(p) iff |{q : dist(p,q) ≤ ε}| ≥ MinPts
Noise: points not density-reachable from any core point → anomaly candidates
One-Class SVM Optimisation min_{w,ξ,ρ} ½||w||² − ρ + (1/νn)Σξᵢ
s.t. w·Φ(xᵢ) ≥ ρ − ξᵢ, ξᵢ ≥ 0
Anomaly: f(x) = sgn(w·Φ(x) − ρ) = −1

Advantages

  • No k needed for clustering (DBSCAN)
  • Works with very few labelled anomalies
  • Non-parametric cluster shapes
  • Kernel OC-SVM captures complex normal manifold
  • Online updating for concept drift

Limitations

  • DBSCAN scales as O(n log n) with k-d tree; slow for very high n
  • ε and MinPts require domain knowledge
  • OC-SVM kernel matrix is O(n²) memory
  • Incremental SVM update is complex
Q4

Dimensionality-reduction + classification pipeline for hyperspectral image patches with change-detection

⚙

1. Problem & Technique Selection

Hyperspectral images have hundreds of spectral bands (200–400). Direct classification suffers from the Hughes phenomenon (curse of dimensionality). Change detection requires efficient feature comparison across time. Selected: PCA (reduction) → k-NN classifier → Background Modelling + Optical Flow (change detection).

3. Stage Explanations

S1

PCA — Dimensionality Reduction

Computes covariance matrix C = (1/n)XᵀX of centred spectral vectors. Eigendecomposition gives principal components; top d eigenvectors (explaining 99% variance) form projection matrix W. Projected data z = Wᵀx has d≪D. This removes spectral redundancy, suppresses sensor noise, and speeds subsequent classifier training. PCA is preferred over t-SNE here because t-SNE is non-linear and non-parametric (cannot project new test patches).

S2

k-NN Classifier (Non-parametric)

In the d-dimensional PCA space, classify each patch by majority vote of its k nearest labelled neighbours using Euclidean distance. Non-parametric: no assumption on class distribution, handles arbitrary class shapes. In low-dimensional PCA space, k-NN is efficient with k-d trees (O(d log n) per query). Output is a per-pixel land-cover label map.

S3

Background Modelling (MOG2)

Models each pixel's spectral history in the PCA-reduced space as a mixture of Gaussians: B(x,t) = Σ wₖ N(μₖ,Σₖ). A new frame pixel is foreground (changed) if its Mahalanobis distance to all background Gaussians exceeds a threshold. The reduced dimensionality makes Gaussian covariance estimation far more reliable (fewer parameters).

S4

Dense Optical Flow (Farneback)

Estimates the 2-D velocity field u(x,y) between consecutive PCA-compressed images using polynomial expansion of local image structure. Flow vectors on foreground pixels from the background model indicate motion direction and speed of changed objects, enabling discrimination of genuine change from illumination shift.

∑

4. Mathematical Principles

PCA — Eigenvalue Problem C·vₖ = λₖ·vₖ, C = (1/n)Xᵀ X
W = [v₁, v₂, …, vd], z = Wᵀ(x − μ̄)
Variance retained = Σ_{i=1}^d λᵢ / Σ_{i=1}^D λᵢ ≥ 0.99
k-NN Decision Rule ŷ(x) = argmax_c |{xₙ : rank(x,xₙ) ≤ k and yₙ=c}|
Bayes error bound: ε*_kNN ≤ 2·ε*(1 − ε*) as k→∞
Optical Flow — Farneback Brightness Constancy I(x,y,t) = I(x+u, y+v, t+1)
Iₓu + Iyv + It = 0 (linearised via Taylor expansion)
Farneback: local polynomial f(x) ≈ xᵀ Aₓ x + bₓᵀx + cₓ

Advantages

  • Solves Hughes phenomenon via PCA
  • k-NN is flexible, no distributional assumptions
  • Dense optical flow captures motion field
  • Near-real-time (PCA projection is fast)
  • PCA noise filtering improves MOG2 reliability

Limitations

  • PCA discards discriminative non-linear structure (LDA better for class separation)
  • k-NN slow at test time for large databases
  • Optical flow assumption (brightness constancy) violated under illumination change
  • t-SNE cannot map new samples (cannot use for test)

Hybrid feature extraction for linear & textured structures in multi-resolution satellite images

⚙

1. Problem & Technique Selection

Roads are thin, elongated, multi-scale; rivers have curved, blurred banks; crop patterns are periodic textures. Atmospheric noise degrades gradients. A hybrid strategy is required: Image Pyramids + LoG (scale-space), Gabor filters (orientation), DWT (frequency decomposition), and SIFT (invariant feature points).

3. Stage Explanations

S1

Image Pyramids + Laplacian of Gaussian (LoG)

Gaussian pyramid provides images at scales σ·2^l. LoG = ∇²G(x,y;σ) detects blobs (road intersections, crop circles) as zero-crossings. Scale-normalised LoG: σ²·∇²G. The DoG (Difference of Gaussians) approximates LoG cheaply. Responses at multiple pyramid levels locate structures at their characteristic scale, immune to atmospheric zoom-dependent blur.

S2

Gabor Filter Bank

Gabor kernel: g(x,y;λ,θ,σ,γ) = exp(−(x'²+γ²y'²)/2σ²)·cos(2πx'/λ). A bank with 8 orientations (0°, 22.5°, …, 157.5°) and 5 scales captures oriented structures (road edges, river banks) at each direction. Gabor is optimally localised in both space and spatial frequency (uncertainty principle). Crop rows with periodic spacing have peak Gabor response at spacing=λ.

S3

Discrete Wavelet Transform (3-level)

Decomposes the image into subbands: LL (approximation), LH (horizontal edges), HL (vertical edges), HH (diagonal details) at each level. Atmospheric noise (mostly high-frequency) is captured in HH and can be thresholded (denoising). Road textures occupy specific frequency bands, making DWT coefficients strong texture discriminators. Multi-level decomposition naturally provides multi-resolution analysis.

S4

SIFT Keypoints + Descriptors

Detects extrema in DoG scale-space; assigns orientation from gradient histogram; computes 128-D descriptor from 4×4 histograms. Scale and rotation invariant. SIFT localises road intersections, bridge endpoints, and landmark crop features that recur across different satellite passes, enabling temporal change detection.

∑

4. Mathematical Principles

Scale-Normalised LoG LoG_σ(x,y) = σ² · (∂²G/∂x² + ∂²G/∂y²) * I(x,y)
DoG(x,y,σ) ≈ LoG_σ(x,y) [Lindeberg 1994]
Gabor 2-D Filter g(x,y;θ,λ,σ) = exp(−(x'²+γ²y'²)/2σ²) · cos(2πx'/λ)
x' = x·cos(θ)+y·sin(θ), y' = −x·sin(θ)+y·cos(θ)
DWT 2-D Subband Decomposition LL = (H_rows ⊗ H_cols) * I
LH = (H_rows ⊗ G_cols) * I, HL = (G_rows ⊗ H_cols) * I
HH = (G_rows ⊗ G_cols) * I
H = low-pass wavelet filter, G = high-pass (detail) filter

Traffic signs are partially occluded, appear at varying distances, and must be detected under illumination variation. The chosen pipeline: Contour Extraction (Suzuki-Abe) → Ellipse Fitting (RANSAC) → Randomised Hough Transform, with multi-resolution preprocessing to handle scale variation.

3. Stage Explanations

S1

Multi-resolution Preprocessing

Apply Gaussian pyramid (3 levels) to detect signs at multiple distances. Canny edge detection with adaptive thresholds (Otsu-based) handles varying illumination.

S2

Suzuki-Abe Contour Extraction

Traverses the binary edge image using a border-following algorithm to output a hierarchical contour tree. Provides structured boundary representation (including parent-child nesting: outer sign boundary → inner symbol), enabling shape-based filtering. More informative than simple connected-component labelling.

S3

Douglas-Peucker Contour Simplification

Iteratively removes contour points that are within ε pixels of the line between their neighbours. Reduces contour point count by 60–80%, reducing RANSAC fitting cost. Preserves curvature maxima (corners of ellipse) which are key for fitting.

S4

RANSAC Ellipse Fitting

Repeatedly samples 5 points (minimum to fit a conic), fits an ellipse via Direct Least Squares, counts inliers within distance ε of the fitted ellipse. Robust to up to 50% outliers (occluded portions of sign). More robust than Direct Least Squares alone (which is sensitive to outliers). Returns the ellipse with maximum inlier count after N iterations.

S5

Randomised Hough Transform (RHT) Verification

Randomly selects 3 edge points, computes the unique circle through them (via circumcircle formula), accumulates (cx, cy, r) in parameter space. RHT needs only O(1) memory accumulator update vs. CHT's O(r) per edge point. Verifies whether the RANSAC ellipse is actually circular (for circular signs). Discards ellipses with too high eccentricity.

⚙

1. Problem & Technique Selection

Blood vessels are thin (1–3 voxels), tubular, with intensity variation along their length, and must be separated from surrounding tissue. Pipeline: Hessian-based Vesselness Filtering → Region Growing (seed-based) → Graph-Cut refinement.

3. Stage Explanations

S1

Hessian-based Vesselness Filtering (Frangi 1998)

At scale σ, compute the Hessian matrix H(x;σ) = σ² · [∂²G/∂xᵢxⱼ] * I(x). Eigenvalues λ₁≤λ₂≤λ₃ of H characterise local geometry: for a bright tubular vessel, λ₁≈0, λ₂<0, λ₃<<0. Frangi vesselness measure: V(x;σ) = exp(−R_A²/2α²)·(1−exp(−R_B²/2β²))·(1−exp(−S²/2c²)). Applying at multiple σ values and taking max selects vessels at their characteristic scale. This preserves thin structures that intensity thresholding would miss.

S2

Seeded Region Growing

User places seeds inside a vessel segment. Algorithm adds neighbouring voxels if |I(neighbour) − mean(region)| < threshold T. Grows along the vesselness-enhanced image rather than the raw intensity, preventing leakage into surrounding tissue (different Hessian signature). Threshold T adapts locally: T = k·σ_region, preventing leakage as the region grows.

S3

Graph-Cut Refinement

Constructs a graph where t-links encode P(voxel = vessel) from the vesselness map; n-links encode intensity similarity. Min-cut separates vessel from background globally, correcting leaks and gaps from region growing. User background scribbles add hard background constraints.

S4

Centreline Extraction

Topological thinning (skeletonisation) of the segmented binary volume extracts the vessel centreline — a topologically correct tree used for stenosis measurement and surgical planning.

∑

4. Mathematical Principles

Frangi Vesselness Measure R_A = |λ₂|/|λ₃| (plate vs. tube), R_B = |λ₁|/√(|λ₂λ₃|) (blob)
S = ||H||_F = √(λ₁²+λ₂²+λ₃²) (structureness)
V(s) = (1−exp(−R_B²/2β²)) · exp(−R_A²/2α²) · (1−exp(−S²/2c²))
Adaptive Region Growing Criterion Add voxel q to region R iff:
|I(q) − μ_R| ≤ k · σ_R and V(q) ≥ θ_vessel
μ_R = mean intensity of region, σ_R = std dev of region

Advantages

  • Hessian detects thin 1–2 voxel vessels missed by thresholding
  • Multi-scale vesselness handles varying vessel calibres
  • Graph-Cut globally optimal — prevents topological errors
  • User seeds enable interactive refinement

Limitations

  • Hessian fails at vessel bifurcations (eigenvalue structure breaks down)
  • Region growing can still leak at stenotic regions
  • Graph-Cut memory O(V³) for 3-D — volumetric graphs are large
  • Centreline extraction sensitive to holes in segmentation

3. Stage Explanations

S1

Feature Extraction

FFT spectrum (top-k frequency amplitudes corresponding to bearing fault frequencies), RMS, kurtosis, crest factor. Kurtosis is particularly sensitive to impulsive fault signatures. These form the high-dimensional input feature vector.

S2

K-Means++ Clustering

Initialises centroids with D²-weighted probability (each new centroid chosen with probability proportional to squared distance from existing centroids), avoiding the worst-case clustering of K-Means random init. Minimises Σ||xᵢ−μ_{c(i)}||². Discovers k natural operating modes (e.g. normal, worn bearing, misalignment). Better initialisation than GMM for high-dimensional vibration data.

S3

Cluster Labelling with Scarce Labels

Expert labels a few samples from each cluster. Propagate labels to all cluster members. This is semi-supervised: we exploit the unlabelled structure found by K-Means++ to amplify scarce labels.

S4

Bayesian Classifier + Mahalanobis Distance Discriminant

Each class k is modelled as a Gaussian N(μₖ, Σₖ) estimated from cluster members. The Mahalanobis distance d_M(x,k) = √((x−μₖ)ᵀ Σₖ⁻¹ (x−μₖ)) accounts for inter-feature correlations, unlike Euclidean distance. Bayesian decision: class* = argmax P(k)·N(x;μₖ,Σₖ). A sample declared anomalous if min_k d_M(x,k) > threshold T (χ² distribution with d.f. = feature dimension).

∑

4. Mathematical Principles

K-Means++ Initialisation P(x chosen as next centroid) ∝ min_c ||x − c||²
Convergence guarantee: E[cost] ≤ O(log k) · optimal cost
Mahalanobis Distance & Anomaly Decision d_M(x, μₖ, Σₖ) = √((x−μₖ)ᵀ Σₖ⁻¹ (x−μₖ))
Under normality: d_M² ~ χ²(p), p = feature dimension
Anomaly if: min_k d_M(x,k) > χ²_{p, 0.99} (99th percentile)
Bayesian Decision Rule class* = argmax_k log P(k) − ½log|Σₖ| − ½d_M²(x, μₖ, Σₖ)

Advantages

  • K-Means++ avoids poor local minima
  • Mahalanobis handles correlated features (vibration bands correlate)
  • Works with very few labelled faults
  • χ² threshold is theoretically grounded

Limitations

  • K-Means++ assumes spherical clusters (GMM better for ellipsoidal)
  • Σₖ inversion ill-conditioned when features > samples
  • k must be specified (requires domain knowledge of fault types)
  • Sensitive to non-Gaussian distributions

Projects D-dimensional appearance+spatial features to d-dimensional subspace. Preserves maximum variance, removes correlated noise from multiple cameras. Real-time: projection is a d×D matrix multiply per frame, O(dD) per vector.

3. Stage Explanations

S1

Image Pyramid + Dehazing

Apply dark channel prior or Retinex-based dehazing at each pyramid level to restore contrast lost in fog. Gaussian pyramid (5 levels) then provides scale-space for detecting lane markings near and far.

S2

Phase Congruency (Kovesi)

Unlike Canny which detects intensity gradient maxima, Phase Congruency detects features where Fourier components are maximally in phase: PC(x) = E(x) / (Σ_n A_n + ε). This measure is independent of absolute intensity (illumination invariant) and relative to noise level. Critically superior to Canny and LoG in fog and rain where gradients are weak but phase coherence persists at lane markings.

S3

Progressive Probabilistic Hough Transform (PPHT)

Samples a random subset of edge points; accumulates in (ρ,θ) space. When a peak exceeds threshold, traces the full line segment; removes those edge points. Terminates when remaining edge density is low. ~10× faster than standard Hough with comparable accuracy. LSD (Line Segment Detector) is gradient-based and faster still but less robust to fog-degraded gradients.

S4

AGAST (Adaptive & Generic Accelerated Segment Test)

An optimised decision tree for FAST corner detection, 2× faster than FAST. Adapts the decision tree based on observed pixel distribution, achieving ~200 fps. Critical for real-time sign detection under rain where temporal coherence must be exploited by tracking keypoints frame to frame.

S5

HOG Descriptors

Divide detection window into 8×8 cell blocks; compute gradient orientation histogram (9 bins, 0–180°) per cell; normalise over 2×2 block (L2-Hys). HOG captures shape and silhouette of traffic signs robustly. Unlike SIFT, HOG operates on a dense grid — crucial for detecting standardised sign shapes even in low contrast. HOG + linear SVM is the classic pedestrian/sign detector (Dalal & Triggs 2005).

3. Stage Explanations

S1

Non-Local Means (NLM) Speckle Filtering

Replaces each pixel value with a weighted average of similar-appearing patches across the image: û(p) = Σ_q w(p,q)·u(q), w(p,q) ∝ exp(−||patch(p)−patch(q)||²/h²). Removes speckle while preserving organ boundary sharpness, unlike Gaussian smoothing which blurs boundaries.

User places markers inside the organ and in the background. Watershed flooding from these markers creates bounded catchment basins that prevent over-segmentation. S3

Initialise snake on Watershed boundary. GVF extends the edge-attraction field deep into homogeneous regions: it solves ∂u/∂t = μ∇²u − (u−∇|∇I|)·(∇|∇I|)², where u(x,y) is the flow field. S4

The Snake boundary initialises the foreground/background appearance models. Graph-Cut then globally optimises the binary labelling, correcting errors at shadow artefact regions where the Snake may have leaked. User scribbles on shadow regions provide additional background constraints.

Spectral Clustering

Constructs affinity matrix W where W_{ij} = exp(−||xᵢ−xⱼ||²/2σ²). Graph Laplacian L = D − W; compute top k eigenvectors of L. Cluster in the eigenspace using K-Means. S3

Confirmed normal flows (low error, no alert) retrain the autoencoder via mini-batch SGD every T minutes. The spectral clustering affinity matrix is updated with an exponential moving average of recent pairwise distances, adapting to new normal protocol versions.

3. Stage Explanations

S1

Linear Discriminant Analysis (LDA)

Finds the d = C−1 linear projections that maximise between-class scatter S_B while minimising within-class scatter S_W: W = argmax |WᵀS_BW| / |WᵀS_WW|. Unlike PCA (maximises total variance), LDA explicitly preserves class-discriminative information between object classes (vehicles, pedestrians, vegetation). This improves both MOG2 segmentation (class-specific background models) and KDE density estimation. Solves generalised eigenvalue problem: S_B·w = λ·S_W·w.

S2

Parzen Window KDE (Non-parametric Density)

In the LDA subspace, models the appearance distribution of each object class non-parametrically. Used for object likelihood computation during tracking: P(class=k | observation) ∝ p̂_k(x). The LDA subspace makes KDE effective because it concentrates class-specific density, reducing bandwidth requirements.

S3

MOG2 Background Subtraction in LDA Space

Background model in the compact LDA space requires fewer Gaussian components per pixel. Foreground detection is class-aware: spectral signatures of vehicles differ strongly from vegetation in the LDA projection, reducing false positives.

S4

Farneback Dense Optical Flow

Computed on the LDA-compressed representation between frames t and t+1. Polynomial expansion approximates the local signal as a quadratic, and the displacement field is estimated by equating polynomials after motion. Dense flow gives a velocity vector at every foreground pixel, enabling accurate trajectory estimation for all tracked objects.

3. Stage Explanations

S1

BM3D Noise Suppression

Block-Matching 3D filtering: groups similar patches into 3-D arrays, applies 3-D transform (wavelet), thresholds, reconstructs. Preserves grain boundary sharpness better than Gaussian smoothing. Electron shot noise in TEM is approximately Poisson-distributed, and BM3D handles this effectively.

S2

Gaussian Pyramid + Derivative Filters

Gaussian derivatives ∂G/∂x, ∂G/∂y, ∂²G/∂x², ∂²G/∂x∂y at scales σ, 2σ, 4σ. These form a complete set of local jet descriptors. S3

Log-Gabor Filter Bank

Log-Gabor avoids the DC component issue of standard Gabor (standard Gabor has a non-zero mean if the bandwidth is large): it is symmetric on a log-frequency axis. Ideal for bandpass filtering: g(f) = exp(−(log(f/f₀))²/2(log(σ_f/f₀))²). Bank of 6 orientations × 4 frequencies captures grain boundary orientations and periodic lattice spacings in crystal materials with high sensitivity. Avoids the artificial constraint of even-symmetric Gabor at high bandwidth.

S4

Curvelet Transform

Curvelets are a multi-scale representation optimally suited to represent curve-like singularities (grain boundaries, dislocation lines). Unlike wavelets (isotropic), curvelets are directional at each scale with anisotropy ratio = 2^{-j/2} at scale j. This makes curvelet coefficients sparse for grain boundary images: few large coefficients → efficient boundary encoding. Replaces DWT when structures are elongated/curved rather than axis-aligned.

S5

SIFT Keypoints

Detects reproducible feature points at nanoparticle locations, lattice defects, and grain triple junctions. SIFT descriptors enable cross-sample matching: identifying the same grain structure across multiple TEM images of different sample regions, supporting statistical grain analysis.
