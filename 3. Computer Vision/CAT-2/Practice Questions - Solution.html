Nighttime security camera — compare Canny, LoG, DoG for edge detection. Select the most suitable method with justification.
10 Marks
Problem

Nighttime images suffer from high noise (sensor noise, low light) and weak/blurred boundaries. The chosen edge detector must suppress noise while precisely localising edges.

Pipeline

Pipeline for Canny edge detector (recommended choice)

Comparison of Techniques
PropertyCannyLoG (Marr-Hildreth)DoG
Noise HandlingExcellent — built-in GaussianGood — Laplacian on smoothed imgModerate — approximates LoG
LocalizationExcellent (sub-pixel via NMS)Good (zero-crossing)Lower precision
Thin edgesYes (NMS ensures single pixel)Can be thickBlobs rather than edges
ThresholdingHysteresis (two thresholds)Single zero-crossingSingle threshold
Computational costMediumMediumLow
Best for nighttime?✓ Best choiceAcceptableNot ideal
Mathematical Principle

Canny — Step by Step:

1. Gaussian smoothing: G(x,y) = (1/2πσ²) · exp(-(x²+y²)/2σ²) Smoothed image: I_s = I * G 2. Gradient magnitude: M(x,y) = √(Gx² + Gy²) Gradient direction: θ(x,y) = arctan(Gy / Gx) 3. Non-Maximum Suppression (NMS): Keep pixel only if M(x,y) > neighbours along gradient direction 4. Hysteresis Thresholding: Edge pixel if M > T_high Connected edge pixel if T_low < M < T_high Discard if M < T_low

LoG Principle:

LoG(x,y) = -1/(πσ⁴) · [1 - (x²+y²)/2σ²] · exp(-(x²+y²)/2σ²) Edge = zero crossing of ∇²G * I

DoG (approximation of LoG):

DoG(x,y) = G(x,y,σ₁) - G(x,y,σ₂) where σ₂ ≈ k·σ₁ (k≈1.6)
Justify Selection
Canny is the optimal choice for nighttime security camera images

Canny satisfies all three optimality criteria: Good Detection (low probability of false/missing edges), Good Localization (detected edges close to true edges), and Single Response (one response per true edge). The hysteresis thresholding is critical for weak boundaries in low-light scenes.

Advantages — Canny

  • Best noise suppression via Gaussian
  • Thin, precise single-pixel edges
  • Hysteresis avoids spurious gaps
  • Tunable σ for noise level

Limitations — Canny

  • Computationally heavier than Sobel
  • Sensitive to σ and threshold values
  • May miss very faint edges
  • Not rotation-invariant by default

Robot warehouse pipeline — edge detector + Hough Transform + corner detector. Explain each stage.
10 Marks
Problem

A warehouse scene contains shelves (straight edges), box boundaries (structural lines), and corners. The robot needs to locate and navigate using these geometric primitives.

Full Pipeline
Stage Explanations
1

Canny Edge Detector — Boundary Extraction

Purpose: Convert the warehouse image into a binary edge map. Shelves, box outlines, structural walls appear as white edge pixels on black background. Noise is suppressed by the Gaussian kernel.

Expected output: A binary image where every structural line is represented as a 1-pixel-wide curve. Box corners visible as edge intersections.

2

Hough Line Transform — Line/Structure Detection

Purpose: Detect dominant straight lines (shelves, aisle boundaries, box sides) from the edge map. Votes in (ρ, θ) parameter space; peaks correspond to real lines.

Expected output: A list of parametric lines (ρ, θ) representing every shelf edge, wall, and box boundary. These serve as structural primitives for navigation.

3

Harris Corner Detector — Feature Keypoint Extraction

Purpose: Find corner points (box corners, shelf intersections) that are distinctive and repeatable. These serve as spatial landmarks for robot localisation and map-building.

Expected output: A set of (x, y) coordinate points marking all significant corners — used for odometry correction or SLAM.

Mathematical Principle

Hough Transform:

Line in image space: y = mx + c Line in Hough space: ρ = x·cos(θ) + y·sin(θ) Each edge point (x,y) votes for all (ρ,θ) satisfying the equation. A peak at (ρ₀,θ₀) in the accumulator = a line in the image.

Harris Corner Detector:

Structure tensor M = Σ w(x,y) [Ix² IxIy] [IxIy Iy² ] Corner Response: R = det(M) - k·trace(M)² (k ≈ 0.04-0.06) R >> 0 → Corner R << 0 → Edge |R| ≈ 0 → Flat region

Advantages

  • Hough tolerates gaps in edges
  • Harris is rotation invariant
  • Pipeline is modular and real-time
  • Combines global (lines) + local (corners)

Limitations

  • Hough is O(N·θ) — expensive for dense scenes
  • Harris is not scale invariant
  • Clutter/occlusion reduces accuracy
  • Requires careful threshold tuning

Mathematical Principle

Scale-Space & Image Pyramids

A Gaussian pyramid downsamples the image repeatedly (by factor 2) at increasing σ. A DoG pyramid subtracts adjacent Gaussian levels. Keypoints detected as extrema across these layers are inherently scale-invariant. For a product at 3× zoom, it will produce a keypoint at a different pyramid level, but the same normalized descriptor — enabling cross-scale matching.

Image Pyramid: I₀ → I₁ → I₂ → ... Iₙ where Iₖ = ↓2(G * Iₖ₋₁) Scale parameter: σₖ = σ₀ · 2^(k/s) (s = octave subdivisions)
Selected Combination: Hessian-Affine (detector) + SIFT (descriptor)

Advantages

  • Full scale + rotation + affine invariance
  • High repeatability in cluttered scenes
  • 128-d descriptor very discriminative
  • RANSAC removes false matches

Limitations

  • SIFT is patented (use SIFT-like implementations)
  • Slow on mobile (use SURF or ORB for speed)
  • Fails with texture-less surfaces
  • High memory for 128-d vectors

Thermal image defect segmentation — explain Region Growing with seed selection, similarity threshold, and connectivity.
10 Marks
Problem

A thermal image shows an industrial component where a defective region has elevated intensity variations and moderate noise. A few pixel coordinates inside the defect are known (seeds). Objective: segment the entire defective region.

Pipeline
Region Growing — Algorithm
ALGORITHM: Region Growing ─────────────────────────────── Input: Image I, Seed pixels S = {s₁, s₂, ..., sₙ}, Threshold T Output: Region R (set of pixels belonging to defect) 1. Initialize: R = S, Queue Q = S 2. While Q not empty: a. Dequeue pixel p b. For each neighbour n ∈ N(p): [4 or 8-connectivity] If n ∉ R AND |I(n) - mean(R)| < T: Add n to R Enqueue n in Q 3. Return R as segmented defect region
Role of Each Parameter
S

Seed Selection

Seeds should lie clearly inside the defective region — not near boundaries. Poor seeds (near edges or normal tissue) cause region leakage into the non-defective area. In this problem, the "few known pixels" are the seeds. For robustness, multiple seeds are preferred.

T

Similarity Threshold T

T too small: Under-segmentation — defect not fully captured. T too large: Over-segmentation (leakage into healthy area). Optimal T is chosen by analysing the intensity histogram of the defect vs background. Typical thermal: T ≈ 5–15 intensity units.

N

Neighbourhood Connectivity

4-connectivity (up/down/left/right): Stricter, fewer diagonal leakages. 8-connectivity (includes diagonals): Captures more irregular defect shapes. For industrial thermal defects with irregular boundaries, 8-connectivity is preferred.

Mathematical Principle
Homogeneity criterion: H(R) = True if: |I(p) - μ_R| < T for all p in R Where: μ_R = (1/|R|) Σ I(p) [running mean of region] T = user-defined or Otsu-estimated threshold Connectivity: 4-neighbourhood: N₄(p) = {(x±1,y), (x,y±1)} 8-neighbourhood: N₈(p) = N₄(p) ∪ {(x±1,y±1)}
Region Growing is ideal here — known seeds provide exact starting points

Advantages

  • Simple and intuitive algorithm
  • Works well with given seed pixels
  • Captures irregular defect shapes
  • Low computational complexity O(N)

Limitations

  • Sensitive to threshold T choice
  • Leaks through weak boundaries
  • Noise causes erratic growth
  • Requires pre-smoothing for noisy thermal images

Agricultural leaf disease segmentation — hybrid: Region Growing + Edge + Graph-Cut. Interactive user-guided approach.
10 Marks
Problem

A leaf image has noise, non-uniform illumination (veins cast shadows), and weak/diffuse disease boundaries. A purely automatic method fails — an interactive hybrid is needed.

Hybrid Pipeline (Ordered Sequence)
Order & Justification of Each Stage
1

Pre-processing (Gaussian + CLAHE)

Reduce noise (Gaussian blur σ=1) and correct non-uniform illumination using CLAHE (Contrast Limited Adaptive Histogram Equalization). This ensures that intensity-based methods (Region Growing, Graph-Cut) work on a normalised image.

2

User Seeds / Scribbles (Interactive Input)

The user draws green strokes on diseased areas (foreground seeds) and red strokes on healthy leaf (background seeds). These provide class likelihood information: P(FG | pixel), P(BG | pixel).

3

Region Growing (Coarse Segmentation)

Starting from foreground seeds, grow a coarse region using intensity similarity. This produces a rough mask of the diseased area quickly and efficiently, before expensive Graph-Cut is applied.

4

Canny Edge Detection (Boundary Constraint)

Compute edge image using Canny. These edges act as boundary cues for Graph-Cut — strong edges carry high edge-weight penalties that prevent the min-cut from crossing real boundaries.

5

Graph-Cut (Fine Refinement)

Build a graph where every pixel is a node. Source = FG seed terminal, Sink = BG seed terminal. Edge weights encode: regional term (colour likelihood from GMM) + boundary term (Canny edge magnitude). Min s-t cut = optimal segmentation boundary.

Mathematical Principle — Graph-Cut
Energy function to minimise: E(f) = Σ_p D_p(f_p) + λ · Σ_{p,q} V_{pq}(f_p, f_q) [regional term] [boundary smoothness term] Where: D_p(FG) = -log P(I_p | FG) [GMM likelihood from seeds] D_p(BG) = -log P(I_p | BG) V_{pq} = exp(-||I_p - I_q||² / 2σ²) · [f_p ≠ f_q] (high weight at edges → discourages cuts) Min-cut = solution f* that minimises E(f)
Hybrid: Region Growing → Edge Detection → Graph-Cut gives optimal results

Advantages

  • User seeds guide ambiguous regions
  • Graph-Cut produces globally optimal boundary
  • Edge term prevents boundary leakage
  • Handles non-uniform illumination

Limitations

  • Graph-Cut is O(V·E) — slow for high-res images
  • Requires user interaction (not fully automatic)
  • GMM must be estimated from sufficient seeds
  • Weak edges still cause boundary leakage

Satellite image flood segmentation — hybrid: Region Growing + Edge-based + Graph-Cut. Role of seeds; reduce leakage.
10 Marks
Problem

A satellite image contains flooded (water) and non-flooded regions. Water pixels have characteristic low-reflectance (dark) intensity in NIR channel. Problems: noise, partial cloud shadow, blurred coastline boundaries. Incorrect segmentation is catastrophically wrong for disaster response.

Hybrid Pipeline
Sequence & Role of Each Stage
StageMethodRoleOutput
1Gaussian DenoisingSuppress speckle/atmospheric noiseSmoothed image
2Seed Points (NDWI > 0 pixels)Identify initial water pixels using spectral indexSeed set S
3Region GrowingExpand flood region from seeds using intensity homogeneityCoarse flood mask
4Edge Detection (LoG/Canny)Detect shoreline/boundary cues to constrain growthEdge map
5Graph-CutGlobally optimise boundary using edges + intensity priorsFinal flood mask
Seed Points Strategy

In satellite imagery, NDWI (Normalized Difference Water Index) is used to auto-generate seeds:

NDWI = (Green - NIR) / (Green + NIR) Seed pixels: all (x,y) where NDWI > 0 AND confidence high (central flood zone) These avoid boundary ambiguity and reduce leakage risk
How Combined Approach Reduces Leakage
  • Region Growing alone leaks through weak shoreline boundaries into adjacent shadow areas (similar intensity to water)
  • Edge detection adds explicit boundary where Region Growing would leak — acts as a stopping criterion
  • Graph-Cut adds a global energy term that simultaneously penalises crossing strong edges and deviating from seed colour model — prevents both leakage and under-segmentation
  • Combined: Region Growing gives fast coarse mask → Edge gives boundary map → Graph-Cut refines to pixel-precise boundary
Mathematical Principle
Region Growing stop condition: |I(n) - μ_flood| > T → stop (boundary found) Graph-Cut boundary term enhanced by edges: V_{pq} = exp(-‖I_p - I_q‖²/2σ²) + α · E_{pq} where E_{pq} = Canny edge magnitude between p and q → High E_{pq} makes cutting between p,q very expensive → Min-cut automatically follows the detected edge
Hybrid approach with NDWI seeds + Region Growing + LoG edges + Graph-Cut

Advantages

  • NDWI seeds are domain-informed, reliable
  • Dramatically reduces region leakage
  • Graph-Cut gives globally optimal segmentation
  • Applicable to large-scale disaster mapping

Limitations

  • Graph-Cut expensive for large satellite images
  • Cloud shadow misidentified as water
  • NDWI inaccurate for turbid/shallow water
  • Requires multi-spectral (NIR) bands

Manufacturing plant anomaly detection — K-Medoids/GMM clustering + Bayes/KNN/ANN classifier + discriminant function. Limited labelled data.
10 Marks
Problem

High-dimensional sensor measurements (vibration, temperature, current) with very few labelled anomaly samples. Need: (a) unsupervised clustering, (b) semi-supervised classification, (c) anomaly scoring via discriminant functions.

Full Pipeline
Part (a) — K-Medoids vs GMM
PropertyK-MedoidsGMM (EM)

Soft assignmentsNo (hard)Yes (posterior probabilities)
Handles noiseBetter than K-meansCan if initialised well
Best here?For robust initial grouping✓ For probabilistic model of normal behaviour

GMM is preferred because it gives P(x | cluster k) — this probability directly feeds into the anomaly discriminant function.

GMM: P(x) = Σₖ πₖ · N(x | μₖ, Σₖ) EM: E-step: γ(z_nk) = πₖN(xₙ|μₖ,Σₖ) / Σⱼ πⱼN(xₙ|μⱼ,Σⱼ) M-step: μₖ = Σₙ γ(z_nk)xₙ / Nₖ
Part (b) — Classifier Selection
ClassifierBayesKNNANN
Labelled data neededLow (model-based)ModerateHigh
Semi-supervised?PartiallyYes (label propagation)Yes (self-supervised)
With few anomaly labelsOverfits to majority class✓ Works wellNeeds more data
RecommendationBaseline only✓ Best hereIf more data available

KNN is selected — because it is non-parametric (no assumption on distribution), and with GMM-reduced features, K=3 or K=5 can effectively identify anomalies by comparing a new sample to its K nearest neighbours in feature space. Abnormal samples will have K nearest neighbours that are all normal (large distance) or clustered in anomaly space.

Part (c) — Discriminant Function + Outlier Effect
Linear Discriminant: g(x) = wᵀx + w₀ Class 1 (anomaly) if g(x) > 0, else Class 0 (normal) Probabilistic Discriminant (Bayes optimal): g(x) = log[P(x|anomaly) · P(anomaly)] - log[P(x|normal) · P(normal)] Anomaly if g(x) > threshold δ GMM-based anomaly score: A(x) = -log P(x) = -log Σₖ πₖ N(x | μₖ, Σₖ) High A(x) → x is anomalous (low likelihood under normal model)

Effect of Outliers: Outliers in training data shift the mean μ and inflate covariance Σ of GMM components, causing the normal model to appear broader — this reduces sensitivity to anomalies. K-Medoids is preferred for initialising GMM when outliers are present, since medoids are robust to extreme values.

Advantages

  • GMM models sensor distributions probabilistically
  • KNN works well with very few labels
  • Discriminant gives interpretable score
  • Semi-supervised exploits unlabelled data

Limitations

  • GMM sensitive to #components (K)
  • KNN is O(N) per query in high dimensions
  • Discriminant fails if classes overlap
  • Outliers corrupt covariance estimates

Video analysis — PCA/LDA/ICA dimensionality reduction + non-parametric method + Background Subtraction + Optical Flow for tracking.
10 Marks
Problem

High-dimensional visual features (HOG, colour histograms) from a fixed-camera scene. Need to reduce dimensions, then track moving objects using background modelling and optical flow.

Complete Pipeline
Dimensionality Reduction — PCA vs LDA vs ICA
MethodObjectiveSupervised?Output
PCAMaximise variance (compress data)NoUncorrelated components
LDAMaximise class separabilityYesDiscriminant axes
ICAStatistical independence of sourcesNoIndependent sources
Select: PCANo class labels needed in videoNoLow-dim variance-rich features

PCA selected because video feature extraction is unsupervised (no object labels per frame), and PCA efficiently retains variance-rich features while reducing computation for downstream KNN.

PCA: Covariance: C = (1/N) Σᵢ (xᵢ - μ)(xᵢ - μ)ᵀ Eigenvectors: C·v = λ·v Project: y = Vₖᵀ(x - μ) [Vₖ = top k eigenvectors] Computational effect: Original: d = 1000 → PCA → k = 50 dimensions KNN distance: O(d·N) → O(k·N) [20× speedup]
Background Subtraction

A background model B(x,y) is estimated from static frames (Gaussian Mixture Model per pixel — MOG2). For each new frame I_t:

Foreground mask: F(x,y) = 1 if |I_t(x,y) - B(x,y)| > τ 0 otherwise MOG2 adapts: B(x,y) updated incrementally B_new = α · I_t + (1-α) · B_old [α = learning rate ≈ 0.01]

Output: Binary foreground mask showing moving objects (people, vehicles).

Optical Flow — Motion from Consecutive Frames

Lucas-Kanade Optical Flow estimates per-pixel velocity vector (u,v) assuming brightness constancy:

Brightness constancy: I(x,y,t) = I(x+u, y+v, t+1) Taylor expansion → optical flow equation: Ix·u + Iy·v + It = 0 [one equation, two unknowns] Lucas-Kanade (local window W): [Σ Ix² Σ IxIy] [u] [-Σ IxIt] [Σ IxIy Σ Iy² ] [v] = [-Σ IyIt] Solved if AᵀA is non-singular (Harris condition!) Direction of motion: θ = arctan(v/u), Speed = √(u²+v²)

Advantages

  • PCA dramatically reduces KNN cost
  • MOG2 handles gradual illumination change
  • LK flow gives dense motion vectors
  • Combined: robust detection + trajectory

Limitations

  • PCA may discard discriminative info (LDA better if labels exist)
  • BG subtraction fails if camera moves
  • LK flow fails at large displacements
  • Shadows cause false positives in BG mask

Surveillance — PCA/LDA/ICA + KNN on reduced features + BG Subtraction + Optical Flow to detect and track moving people.
10 Marks
Problem

A surveillance camera sees many people. System must (a) reduce feature dimensions, (b) classify with KNN, (c) use BG subtraction and optical flow together to detect and track people.

Pipeline
Part (a) — Dimensionality Reduction

LDA is preferred here because surveillance has labelled person identities (multiple people tracked with IDs). LDA maximises the ratio of between-class to within-class scatter — better for re-identification tasks.

LDA Objective: Maximize: J(W) = |WᵀS_B W| / |WᵀS_W W| S_B = Σₖ Nₖ (μₖ - μ)(μₖ - μ)ᵀ [Between-class scatter] S_W = Σₖ Σ_{xᵢ∈Cₖ} (xᵢ - μₖ)(xᵢ - μₖ)ᵀ [Within-class scatter] Solution: W = S_W⁻¹ · S_B eigenvectors (top c-1 for c classes)
Part (b) — KNN on Reduced Features

After LDA, each person's feature vector lives in a (c−1)-dimensional space. KNN assigns the class of the K nearest training vectors by Euclidean distance.

KNN Decision: d(x, xᵢ) = ‖y - yᵢ‖₂ [distance in reduced space y = Wᵀx] Class = mode of labels of K nearest neighbours Computational cost comparison: Without reduction: O(N · d) where d = 1000+ After LDA (dim = c-1 ≈ 10-20): O(N · (c-1)) Speedup: d/(c-1) ≈ 50-100× faster per query

KNN with reduced features also has lower curse of dimensionality — distances become more meaningful in low-dimensional LDA space.

Part (c) — BG Subtraction + Optical Flow Together
BG

Background Subtraction — Detect Who is Moving

MOG2 models each pixel as a mixture of Gaussians. Pixels that deviate from background model are marked as foreground → gives binary blobs indicating person positions. Morphological operations (erosion/dilation) clean up the mask.

OF

Optical Flow — Estimate Direction & Speed

Applied to foreground regions only (mask restricts computation). Dense Farnebäck or sparse Lucas-Kanade flow gives velocity vectors (u,v) per foreground pixel. Mean vector over a person-blob = their direction and speed. Multiple people → separate blob clusters → separate flow vectors.

Combined usage: 1. BG mask M_t = BG_subtract(I_t, B) 2. Detect person blobs: B_1, B_2, ... via connected components on M_t 3. For each blob Bᵢ: (u,v) = mean LK flow over Bᵢ pixels direction θᵢ = arctan(vᵢ/uᵢ) speed sᵢ = √(uᵢ² + vᵢ²) 4. Track blob Bᵢ across frames → trajectory

Advantages

  • LDA gives class-discriminative reduction
  • BG subtraction is computationally cheap
  • Optical flow gives per-person direction
  • Combined: detection + identity + motion

Limitations

  • LDA needs class labels (not always available)
  • BG model fails if people stand still
  • Crowded scenes: blob merging problem
  • LK flow fails with fast motion

Industrial inspection — Scale-Space + Gabor/DWT + SIFT/SURF/HOG for defect detection. Compare vs edge/line detector.
10 Marks
Problem

Scratches and textured defects vary in size (micro to macro) and orientation (0°–180°). A single-scale, single-direction filter will miss many defects. Multi-scale, multi-orientation analysis is essential.

Hybrid Pipeline
Part (a) — Scale-Space with Gaussian Pyramid

A defect that is 2px wide at full resolution appears as a 1px defect at half resolution — without scale-space, small defects vanish at coarser scales. The Gaussian pyramid creates a stack of smoothed, downsampled images.

Gaussian Pyramid: L₀(x,y) = I(x,y) [original] Lₖ(x,y) = ↓2[G(σ) * Lₖ₋₁(x,y)] [octave k] Role of Gaussian smoothing: - Removes high-frequency noise before downsampling - Prevents aliasing (Shannon criterion) - At each level, detector finds defects of different sizes: Level 0 → fine scratches (2-5px) Level 2 → medium defects (8-20px) Level 4 → large delaminations
Part (b) — Gabor Filters + DWT

Gabor Filters:

Gabor filter: g(x,y;λ,θ,σ,γ) = exp(-(x'²+γ²y'²)/2σ²) · cos(2πx'/λ + ψ) where x' = x·cos(θ) + y·sin(θ) y' = -x·sin(θ) + y·cos(θ) λ = wavelength (controls scale of texture) θ = orientation (0°, 45°, 90°, 135°) σ = Gaussian envelope width Apply bank of Gabor filters at 4-8 orientations × 3-4 scales → 12-32 response maps capturing oriented texture energy

Discrete Wavelet Transform (DWT):

2D DWT decomposes image into 4 sub-bands per level: LL (approx) | LH (horizontal edges) HL (vertical) | HH (diagonal) At each resolution level: LH → horizontal scratches HL → vertical scratches HH → diagonal/cross defects Multi-level DWT (3 levels) → 10 sub-band feature maps Texture anomaly = deviation from expected sub-band statistics
Part (c) — SIFT Contribution + Comparison

Adding SIFT to the pipeline:

  • SIFT detects blob-like defects (pits, bumps) as keypoints in DoG scale-space
  • 128-d SIFT descriptor encodes local gradient structure around each defect point
  • Scale and rotation invariant — works even if component is tilted on inspection conveyor
SIFT contribution to pipeline: 1. Build DoG pyramid over component image 2. Detect keypoints at all scales (extrema) 3. Assign dominant gradient orientation → rotation invariant 4. Compute 128-d descriptor 5. Match against reference (defect-free) template → Unmatched keypoints = defect regions

Computational Limitation

The hybrid approach runs a bank of Gabor filters (e.g., 32 filters), a 3-level DWT, a DoG pyramid, and SIFT descriptor computation for every image. For a 4K resolution component image at 30 fps production line speed, this is computationally prohibitive without GPU acceleration or hardware FPGA implementation. Typical runtime: ~200–500ms per frame on CPU vs 10–20ms with GPU.

Selected: Multi-scale Gabor + DWT + SIFT hybrid — handles all defect types

Advantages

  • Detects defects at all scales simultaneously
  • Gabor captures oriented texture anomalies
  • DWT provides multi-resolution decomposition
  • SIFT adds scale/rotation invariant keypoints
  • High defect recall — critical for safety

Limitations

  • Very high computational cost
  • Many hyperparameters (λ, θ, σ for Gabor)
  • Needs GPU for real-time production speed
  • Large feature vector → needs dimensionality reduction
