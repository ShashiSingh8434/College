Mathematical Principle

The Sobel operator approximates the partial derivatives of the image intensity I(x,y) using two 3×3 convolution kernels:

Sobel Horizontal Kernel (Gx): [ -1 0 +1 ] [ -2 0 +2 ] [ -1 0 +1 ] Sobel Vertical Kernel (Gy): [ -1 -2 -1 ] [ 0 0 0 ] [ +1 +2 +1 ] Gradient Magnitude: |G| = √(Gx² + Gy²) ← measures edge STRENGTH (approximation: |G| ≈ |Gx| + |Gy|) Gradient Orientation (Direction): θ = arctan(Gy / Gx) ← measures edge DIRECTION (in radians)

Each pixel's gradient vector points in the direction of greatest intensity increase. The magnitude tells us how sharp the edge is; the orientation tells us which way the edge runs.

Explanation of Each Stage

Stage 1 — Gaussian Blur (Pre-processing)

Reduces high-frequency noise from the road (gravel, shadows). Without it, gradients from texture pixels incorrectly fire as "edges".

Stage 2 — Sobel Convolution (Gx, Gy)

Gx detects vertical structures (like lane lines running into the distance). Gy detects horizontal structures. Both are needed simultaneously.

Stage 3 — Gradient Magnitude |G|

High |G| → strong edge (bright/dark boundary). Low |G| → flat region (road surface). A threshold on |G| yields a binary edge map separating lane lines from road.

Stage 4 — Gradient Orientation θ

Lane lines are nearly vertical (θ ≈ 70°–110°). By filtering edges to keep only those whose θ falls in the expected range, horizontal cracks or pedestrian crossings are automatically suppressed.

Visual Illustration
Fig 1.1 — Gradient processing: Input → |G| edge map → θ-filtered lane detection
Justification for Selection

Gradient-based methods are ideal for lane detection because lane markings exhibit sharp intensity transitions (white/yellow paint on dark asphalt). The Sobel operator is computationally light (simple 3×3 convolution), real-time capable at 30+ fps, and directly yields both edge strength and direction — essential properties for lane angle estimation in a steering-control loop.

Advantages

  • Fast — O(n) per pixel, suitable for real-time use
  • Simple implementation on embedded GPU/FPGA
  • Orientation θ directly enables lane angle calculation
  • Works well under good lighting conditions

Limitations

  • Sensitive to shadows, rain, and low contrast
  • Fixed Sobel kernel misses multi-scale features
  • Cannot distinguish lane lines from road cracks alone
  • Requires post-processing (Hough transform) for line fitting

Part A — Orientation Assignment (Rotation Invariance)

For every detected keypoint at scale σ, SIFT samples the gradient magnitudes and orientations in a 16×16 neighbourhood. These are binned into a 36-bin (0°–360° in 10° steps) orientation histogram:

Gradient magnitude at pixel (x,y): m(x,y) = √[ (L(x+1,y) - L(x-1,y))² + (L(x,y+1) - L(x,y-1))² ] Gradient orientation: θ(x,y) = arctan[ (L(x,y+1) - L(x,y-1)) / (L(x+1,y) - L(x-1,y)) ] Weighted by Gaussian window (weight reduces contribution from far pixels): w(x,y) = m(x,y) · exp(-(x²+y²) / (2·(1.5σ)²)) Dominant orientation: θ_dominant = argmax[ Orientation Histogram ] Peaks within 80% of dominant → additional orientations assigned

The descriptor is then rotated relative to θ_dominant. This means even if the vehicle rotates 45°, the keypoint's local reference frame rotates with it — the 128-D descriptor remains identical. This is the mechanism of rotation invariance.

Part B — Localization & Filtering via Hessian Matrix

After initial DoG extrema detection, many keypoints lie on edges rather than corners. These are unreliable because small positional shifts cause large descriptor changes. SIFT uses the 2×2 Hessian of the DoG function at that scale to test for this:

2×2 Hessian matrix H at keypoint (x,y): H = [ Dxx Dxy ] [ Dxy Dyy ] where Dxx = ∂²D/∂x², Dyy = ∂²D/∂y², Dxy = ∂²D/∂x∂y Curvature ratio test (edge keypoint elimination): Tr(H) = Dxx + Dyy ← sum of eigenvalues (α + β) Det(H) = Dxx·Dyy - Dxy² ← product of eigenvalues (α · β) Ratio test: Tr(H)² / Det(H) < (r+1)²/r where r = 10 (Lowe's threshold) On an edge: one eigenvalue >> other → ratio is LARGE → REJECTED On a corner: eigenvalues ≈ equal → ratio is SMALL → KEPT
Intuition: On an edge, the surface curves strongly in one direction but is flat in the other (one large eigenvalue, one near-zero). The ratio Tr(H)²/Det(H) becomes very large. In a corner or blob, both principal curvatures are significant, the ratio stays small — keypoint is reliable.

Advantages of SIFT

  • Robust to rotation, scale, and partial illumination changes
  • Hessian filter eliminates ~90% of spurious edge keypoints
  • 128-D descriptor highly distinctive
  • Works under moderate motion blur

Limitations

  • Computationally heavy — not suitable for all embedded systems
  • Severe motion blur defeats orientation histogram reliability
  • Extreme illumination changes can saturate gradient magnitudes
  • Patented (historically); ORB/BRISK used in commercial systems

Problem Analysis
Situation: Large dataset of patient records. Small subset labelled (confirmed disease outcomes). Most records unlabelled. Goal: build an accurate disease prediction classifier. This is a classic semi-supervised learning scenario.

Selected Approach — Semi-supervised Learning

Semi-supervised learning methods like Label Propagation, Self-training, or Co-training use the manifold assumption: data points close in feature space are likely to share labels. The small labelled set provides anchors; the algorithm propagates these labels through the unlabelled data guided by similarity.

Label Propagation (graph-based) core equation: F = (I - αS)⁻¹ · Y where: Y = initial label matrix (known labels + zeros for unlabelled) S = row-normalized affinity matrix S_ij = exp(-||xi - xj||² / σ²) α = propagation factor (0 < α < 1, typically 0.99) F = predicted label scores for all points Unlabelled nodes receive labels from their labelled neighbours via S
Classifier Comparison: Bayes vs KNN vs ANN
ClassifierCore PrinciplePros for this TaskCons for this Task
Naïve Bayes P(Disease|Features) ∝ P(Features|Disease)·P(Disease)
Assumes feature independence		 Fast; works with small labelled sets; probabilistic output (confidence) Independence assumption often violated in patient records (correlated symptoms)
KNN Assign class of K nearest neighbours in feature space No training phase; naturally semi-supervised with label propagation High memory; slow at inference on large datasets; sensitive to irrelevant features
ANN (Neural Network) Learnable non-linear mappings; backpropagation on labelled data; unsupervised pre-training on unlabelled Handles complex feature interactions; autoencoders can pre-train on unlabelled data; scalable; highest accuracy with enough data Needs careful tuning; less interpretable; risk of overfitting on small labelled subset without regularisation
Recommendation & Justification
Best Classifier: ANN with Autoencoder Pre-training

1. An autoencoder is first trained on all patient records (labelled + unlabelled) in an unsupervised fashion to learn a compressed latent representation of health features.
2. The encoder is then fine-tuned as a supervised classifier using only the labelled records — this is transfer learning within semi-supervised learning.
3. This approach extracts rich, non-linear feature interactions (comorbidities, correlated lab values) that Naïve Bayes cannot capture, and avoids the scalability problem of KNN.

Hybrid Multi-scale, Multi-orientation Feature Extraction Pipeline for CT/OCT Volumes
LoG/DoGSteerable FiltersCurveletKAZE/ORB
10 Marks
Problem Context & Technique Selection
Challenge: CT/OCT volumes contain fine tubular structures (vessels, nerves) and textured tissue at multiple scales and orientations with significant noise. No single classical method captures all this.

Solution: A 4-component hybrid pipeline combining scale-space extrema, steerable orientation filters, curvilinear multi-direction transforms, and keypoint descriptors.
End-to-end Pipeline
Fig 5.1 — End-to-end hybrid multi-scale feature extraction pipeline for CT/OCT
Component 1 — LoG / DoG Scale-space Extrema
Laplacian of Gaussian (LoG): LoG(x,y;σ) = -1/(πσ⁴) · [1 - (x²+y²)/(2σ²)] · exp(-(x²+y²)/(2σ²)) DoG approximation (SIFT style): DoG(x,y;σ) = G(x,y;kσ) - G(x,y;σ) where k ≈ √2 Extrema in (x,y,σ) space → blob/vessel detected at its natural scale σ* σ* indicates the radius of the tubular structure: r ≈ √2 · σ*

Contribution: Detects blobs and vessel cross-sections at their characteristic scale. A vessel of radius 2px is detected at σ≈1.4; a larger vessel at σ≈8. Scale invariance is built in.

Component 2 — Steerable Pyramid / Oriented Gaussian Derivatives
Oriented Gaussian derivative (first-order steerable filter): G¹_θ(x,y) = cos(θ)·∂G/∂x + sin(θ)·∂G/∂y Response at orientation θ: R(x,y;θ,σ) = I(x,y) * G¹_θ(x,y;σ) A steerable pyramid decomposes I into K orientations × J scale bands. Nerves and vessels running at angle θ produce maximum response at that θ.

Contribution: Explicit orientation selectivity. A capillary running at 45° produces a strong response only in the 45° filter bank. This enables direction-specific vessel tracking.

Component 3 — Curvelet / Contourlet Transform
Curvelet parabolic scaling (key property): Curvelet at scale 2⁻ʲ has length ≈ 2^(-j/2) and width ≈ 2^(-j) → Anisotropy ratio = length/width = 2^(j/2) (increases with resolution) Curvelets represent curvilinear edges (vessels, nerve fibres) with O(log N) terms vs O(N) terms for wavelets → much sparser, more compact representation Contourlet = LP decomposition + directional filter banks (DFB) in 2D

Contribution: Optimal representation of curved structures (vessel bends, nerve curvature) at multiple orientations and scales simultaneously. Classical wavelets are isotropic — they miss curvilinear geometry.

Component 4 — KAZE / ORB / BRISK Keypoint Descriptors
KAZE builds its scale space using Additive Operator Splitting (AOS): ∂L/∂t = div(c(x,y,t) · ∇L) ← nonlinear diffusion PDE c(x,y,t) = g(|∇Lσ|²) ← conductivity function (Perona-Malik) g(s²) = 1/(1 + s²/k²) KAZE's nonlinear scale space preserves edges while smoothing noise within regions. ORB uses FAST keypoints + BRIEF descriptors with orientation correction (fast, binary).

Contribution: Produces rotation- and scale-invariant local descriptors at keypoints. KAZE is particularly suited to medical images as its nonlinear diffusion respects tissue boundaries during scale-space construction.

Advantages of Hybrid

  • Full scale and rotation invariance across vessel diameters
  • Curvelet captures curved vessel paths missed by wavelets
  • KAZE's nonlinear diffusion preserves tissue edges
  • Feature fusion provides complementary cues

Limitations & Trade-offs

  • Computationally expensive — curvelet/contourlet not real-time on CPU
  • High-dimensional feature vectors may need PCA/selection
  • Integration of 4 components increases system complexity
  • Tuning σ ranges and orientation count requires domain knowledge
Q6
Interactive Segmentation Pipeline — CT/MRI/Ultrasound with Seeded Region Growing, Active Contours & Graph Cut
Region GrowingActive ContourGraph CutMedical Imaging
10 Marks
Problem Statement & Technique Selection
Challenge: Multi-modal volumes (CT/MRI/US) with faint boundaries, intensity inhomogeneities, and partial-volume effects. Manual segmentation is infeasible. Need an interactive, robust pipeline that produces a topologically coherent binary mask.

Selected Techniques (in order):
① Seeded Region Growing (SRG) — coarse initialisation from user seeds
② Active Contour / Level Set — edge-based refinement of boundary
③ Graph Cut / Random Walker — global energy minimization for final clean mask
End-to-end Interactive Segmentation Pipeline
Fig 6.1 — Three-stage interactive segmentation pipeline for multi-modal medical volumes
Stage 1 — Seeded Region Growing (SRG)

Role: Coarse initialisation. The user places foreground seeds inside the target structure and background seeds outside it. Region Growing merges neighbouring voxels to the region if their intensity difference is below a threshold Δ.

Merging criterion: |I(q) - μ_R| ≤ Δ where: I(q) = intensity of candidate neighbour voxel q μ_R = current region mean intensity Δ = user-defined tolerance (or Otsu-derived) Priority queue (min-heap) propagation: At each step, pop voxel with smallest |I(q) - μ_R| → merge if ≤ Δ → Push its unvisited neighbours into queue Result: closed region volume (coarse mask) around the anatomical structure Seeds propagate outward until boundary or Δ-mismatch stops them
Seed injection: User clicks on central slice in the organ lumen → foreground seeds. User clicks on surrounding tissue → background seeds. Seeds are 3D-dilated to voxel neighbourhoods before propagation.
Stage 2 — Active Contour / Level Set Refinement

Role: The coarse mask from SRG is converted to a signed distance function φ(x). The level set (zero level set = contour) evolves under a PDE that pulls the contour toward image edges.

Geodesic Active Contour (GAC) Level Set PDE: ∂φ/∂t = g(|∇I|) · |∇φ| · (κ + F) + ∇g · ∇φ where: φ(x,t) = level set function (signed distance to contour) κ = mean curvature (∇·(∇φ/|∇φ|)) — smoothness term F = speed function (balloon force, user-set) g(s) = edge stopping function = 1/(1 + |∇Gσ*I|²) When |∇I| is large (edge), g→0 → evolution halts → contour locks onto edge When |∇I|≈0 (flat region), g≈1 → contour expands/contracts freely Level sets handle topology changes (splits, merges) automatically
Why level sets over classic snakes? Classic parametric snakes cannot handle topology changes (vessel branching, split lobes). Level sets represent contours implicitly — topology is automatically managed by the zero level set of φ, making them ideal for complex anatomical shapes.
Stage 3 — Graph Cut Energy Minimization

Role: Globally optimize the binary labelling to produce the final clean mask. The refined boundary from the level set initializes graph edge weights.

Graph Cut Energy Function E(L): E(L) = Σ_p D_p(L_p) + λ · Σ_{(p,q)∈ε} V_{pq}(L_p, L_q) Data term (unary): D_p(fg) = -log P(I_p | FG) ← from user-seeded GMM colour model D_p(bg) = -log P(I_p | BG) Smoothness term (pairwise): V_{pq}(L_p, L_q) = exp(-β||I_p - I_q||²) · [L_p ≠ L_q] Penalizes labelling changes between similar neighbours (encourages smooth boundary) Min-cut solution: L* = argmin_L E(L) ← solved exactly in polynomial time via max-flow Seeds → source (FG node) and sink (BG node) with infinite-capacity edges → hard constraints
Leakage prevention: The level-set refined boundary provides strong initialization of the graph edge weights (high V_pq across the contour). Even at weak boundaries, the global optimization through min-cut prevents leakage — the data cost of mislabelling exceeds the smoothness cost at those pixels.
Justification of Hybrid Order & Design
StagePreventsProduces
① SRGNeed for full manual outline; focuses subsequent stages on a small VOICoarse region-of-interest mask
② Level SetOver-segmentation from SRG; handles concavities and topology changesTopologically correct boundary curve
③ Graph CutLeakage across weak edges; disconnected components; over-smoothingGlobally optimal, topologically clean binary mask

Advantages

  • SRG is interactive — minimal user effort (few clicks)
  • Level set naturally handles topology changes (vessel branches)
  • Graph cut gives globally optimal labelling — no local minima
  • Hard seed constraints prevent gross mislabelling
  • Mask is directly usable by downstream quantification modules

Failure Modes & Computational Considerations

  • SRG leaks at very weak edges (close to Δ threshold) — mitigated by level set
  • Level set can get stuck in local minima far from true boundary with bad initialisation
  • Graph cut memory scales as O(V + E) — large 3D volumes need GPU implementation
  • Random Walker (alternative to Graph Cut) more robust to noise but slower
  • Extreme intensity inhomogeneity (MRI field bias) degrades GMM models
